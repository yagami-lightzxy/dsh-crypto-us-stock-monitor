# 策略卡 · RSI2 抄底（0.20.0 默认）

> 胜率与收益平衡后的综合最优解。插件默认预设即此规则，详情页会显示 `RSI2 抄底 · 2/2`。

## 一、规则

**买入（两条同时满足）**

1. RSI(2) ≤ 15
2. 收盘价 > MA200

**离场（满足任一）**

1. 收盘价 > MA10
2. 持有满 30 个交易日（强制离场）

**执行时点**：信号在收盘后确认，次日开盘买入；离场同理，信号确认后次日开盘卖出。

## 二、参数

| 项目 | 值 |
| --- | --- |
| 快速 RSI 周期 | 2 |
| 慢线 | MA10（离场线） |
| 趋势线 | MA200 |
| 最长持有 | 30 根日线 |
| 数据周期 | 日线 |

## 四、风险提示

1. **没有硬止损**。出场只看 MA10，遇到单边暴跌会吃满跌幅（历史最差 -54.7%）。要么按仓位控制单笔风险，要么自己补一条 -2×ATR 硬止损（胜率会降到约 70%）。
2. **小赢大亏结构**。平均盈利 2.8%、平均亏损 4.4%，赢的次数多但每次赢得少，心态上要接受连续几次亏损。
3. **大部分时间空仓**。场内仅 24.5%，一年 120–190 次信号，2022 年只有 24 次。想提高收益只能加杠杆或叠加趋势仓位，不要改规则硬凑。
4. **样本偏差**。回测标的是今天仍然强势的票，且只做多、只测日线；换到 A 股/港股或小盘股需要重新验证。

## 五、每日操作清单

1. 收盘后打开看板，看自选里有没有标的显示「买入」且条件为 `RSI2 ≤ 15`、`价格 > MA200`。
2. 有信号就次日开盘买，单标的仓位不超过总资金 1/N（N = 同时持仓上限，回测最多 14 个）。
3. 持仓每天检查：收盘价站上 MA10 就次日开盘卖出；满 30 根还没走也卖。
4. 同时开仓数量接近上限时，优先选 RSI(2) 更低的（超卖更深）。
